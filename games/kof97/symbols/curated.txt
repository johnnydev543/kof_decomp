# Stage-3 symbols for the KOF97 matching disassembly (tools/disasm/mkasm.py).
#   ADDR  NAME  [| comment]
# P1 addresses (< 0x100000) name a code/data label (the original L_/D_ label stays as an alias, so the
# shift-test tools keep working); other addresses become .equ constants used for absolute operands.
# Sources: Neo Geo hardware/BIOS documentation (registers, BIOS calls and BIOS work RAM), REA/Ghidra
# pseudocode (build/rea/decomp_p1) and runtime observation (--watch / --break / --exec-log).
